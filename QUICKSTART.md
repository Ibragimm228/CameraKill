# Быстрый старт

Краткая инструкция по установке и использованию Camera Blocker.

## Windows

1. Распакуйте архив и зайдите в папку `windows`.
2. Нажмите правой кнопкой на `install.bat` и выберите **«Запуск от имени администратора»**.
3. Дождитесь окончания установки.

Теперь на рабочем столе есть три ярлыка для управления блокировкой (Запустить, Остановить, Статус).

---

## MacOS

1. Откройте Терминал и перейдите в папку проекта:
   ```bash
   cd ~/Downloads/camera-blocker/macos
   ```
2. Дайте права на выполнение скриптов:
   ```bash
   chmod +x *.sh *.py
   ```
3. Запустите установку:
   ```bash
   sudo ./install.sh
   ```

Теперь можно пользоваться командами `camera-blocker-start`, `camera-blocker-stop` и `camera-blocker-status`.

---

## Linux

1. Откройте терминал и перейдите в папку `linux`.
2. Дайте права на выполнение:
   ```bash
   chmod +x *.sh *.py
   ```
3. Запустите установку:
   ```bash
   sudo ./install.sh
   ```

Управление осуществляется через те же команды, что и на macOS, либо через `systemctl`.

---

## Как проверить, что всё работает?

1. Попробуйте открыть любое приложение, использующее камеру (Zoom, Skype, штатное приложение «Камера»).
2. Если вы видите ошибку «Камера не найдена» или просто черный экран — значит, всё работает.
3. Также можно проверить статус через консоль: `camera-blocker-status`.

## Как временно включить камеру?

Если камера всё же понадобилась:
*   **Windows:** Ярлык «Camera Blocker - Остановить».
*   **macOS/Linux:** Команда `camera-blocker-stop`.

После использования не забудьте включить блокировку обратно!
