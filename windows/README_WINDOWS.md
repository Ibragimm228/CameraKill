# Camera Blocker для Windows

Инструкция по установке и управлению блокировщиком камеры в Windows 10/11.

## Быстрая установка

1. Перейдите в папку `windows`.
2. Найдите файл `install.bat`, нажмите на него правой кнопкой мыши и выберите **«Запуск от имени администратора»**.
3. Дождитесь завершения процесса.

После этого камера будет заблокирована. На рабочем столе появятся три ярлыка для удобного управления:
*   🔒 **Camera Blocker - Запустить** — включает мониторинг и блокировку.
*   🔓 **Camera Blocker - Остановить** — временно разрешает работу камеры.
*   📊 **Camera Blocker - Статус** — показывает текущее состояние устройств.

## Как это работает
1. Программа находит все устройства в категории «Камеры» через Диспетчер устройств.
2. Переводит их в состояние «Отключено».
3. Создает задачу в Планировщике заданий для автоматического запуска при старте Windows.
4. В фоне работает скрипт, который каждые 5 секунд проверяет, не включил ли кто-то камеру вручную, и если да — отключает её снова.

## Ручное управление через консоль
Если вам удобнее работать через командную строку (от имени администратора):
*   `python camera_blocker.py --status` — проверка состояния.
*   `python camera_blocker.py --start` — запуск блокировки.
*   `python camera_blocker.py --stop` — остановка.

## Удаление
Чтобы полностью удалить программу и вернуть настройки камеры в исходное состояние, запустите `uninstall.bat` от имени администратора.

## Возможные проблемы
*   **Камера не блокируется:** Убедитесь, что запускали `install.bat` именно от имени администратора.
*   **Python не найден:** Убедитесь, что у вас установлен Python 3.6+ и при установке была выбрана галочка "Add Python to PATH".
*   **Камера не появилась после удаления:** Зайдите в «Диспетчер устройств» -> «Камеры», нажмите правой кнопкой на ваше устройство и выберите «Включить».
